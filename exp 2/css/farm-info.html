Sensors used

  • Soil Moisture Sensor
  • Temperature Sensor
  • Humidity Sensor
  • Rainfall Sensor

Irrigation Workflow

  1. Check the weather conditions
  2. Check soil moisture
  3. Send data to algorithm
  4. Generate report
  5. Notify farmer

Crop Stages:

Germination
Sprouting of the plant on constant moisture.
Tillering
Formation of multiple shoots from the base of the plant.
Grand Growth
Peak water requirement phase with rapid stem elongation.
Maturity
Sugar accumulation phase; irrigation is gradually reduced.
